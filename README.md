Working repo for assets related to: 

title: "Exploring Texture-Level Creative Decisions with penPal, a Novel Handheld Actuated Drawing Tool"

authors: Tucker Rae-Grant, Luke Jimenez, Lea Albaugh, Ken Nakagaki

paper: https://doi.org/10.1145/3772318.3790391

Note that this does not contain full documentation of how to build a working copy of penPal. Please contact Tucker Rae-Grant if you are interested in replicating this work.

/paths contains everything related to the image--> servo command pipeline
/Arduino_code contains everything running on the pen MCU
/3D_models contains .STLs of printable hardware components.
/GUI contains the Processing interfaces. penPal_stepDance is the current version; older versions are in GUI/archive.
